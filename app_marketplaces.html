Каталог майданчиків для купівлі/продажу готових додатків-бізнесів (з юзерами/доходом) і окремо — маркетплейсів готового коду/шаблонів. Загальні "продай речі" застосунки (eBay, OfferUp, Facebook Marketplace) свідомо виключені — тут ідеться про додатки як цифровий актив/бізнес, не побутові товари.

0 🎯 Короткий вердикт (TL;DR)

Два зовсім різні ринки, не плутай: (А) купівля/продаж ГОТОВОГО додатка-бізнесу з реальними юзерами/доходом/рейтингом в сторі — це M&A-майданчики (Acquire.com, Flippa, Empire Flippers, SideProjectors); (Б) купівля ГОТОВОГО КОДУ/ШАБЛОНУ для швидшого білда з нуля — це CodeCanyon і подібні. Для твоєї мети "конвеєр MVP" (розділ з мультикалькулятором) — категорія Б корисніша ЗАРАЗ (прискорює білд), категорія А стане релевантною, коли з'явиться перший реальний застосунок з трохи трафіку/доходу для продажу чи коли захочеш купити готовий актив замість білда з нуля.

Обережно з legacy-назвами: Chupamobile і SellMyApp (класика "app source code" маркетплейсів 2015-2019) — обидва або мертві, або перезапущені новими власниками з невідомою якістю в 2026. Перевіряй свіжі відгуки перед оплатою, не покладайся на стару репутацію бренду.

Чому це прискорює конвеєр, але має підводні камені
  • Готовий шаблон економить тижні білда, особливо для складніших категорій (розділ 8 попереднього звіту — AR-примірка шпалер/фарби — точно швидше стартувати з готового UI-кіта, ніж писати сегментацію стіни з нуля).
  • App Store review guideline 4.3 (spam/шаблонні клони) — той самий ризик, що й у власного мультикалькулятора: голий нередагований шаблон Apple може відхилити як "template app" без унікальності. Потрібна власна доробка (брендинг, локалізація, хоч одна унікальна фіча).
  • Ліцензія — перевіряй, чи дозволяє ліцензія публікацію під власним брендом у сторі (звичайний "regular license" на CodeCanyon зазвичай дозволяє, але читай умови перед покупкою).

3 ✅ Як це лягає на план BuildCalc / MVP-конвеєр

  • Зараз (білд): якщо хочеш пришвидшити мультикалькулятор чи майбутню AR-примірку — перевір CodeCanyon на готові UI-кіти "calculator app" / "AR wall paint" перед білдом з нуля через Claude Code. Це не заміна Claude Code, а стартовий каркас UI, який Claude Code довершить.
  • Після першого релізу (продаж/оцінка): коли BuildCalc матиме перші реальні завантаження/відгуки — SideProjectors чи Flippa це місце, де можна або продати весь актив, або просто помоніторити, скільки коштують подібні tools-додатки на реальному ринку (орієнтир для власної оцінки прогресу конвеєра).
  • Не купувати готовий "revenue-generating app" з невідомого джерела на ранньому етапі — мета зараз саме навчитись будувати й публікувати самому, а не купувати чужий результат.
